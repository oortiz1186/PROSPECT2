# PROSPECT2

CRM ligero de prospección para administrar empresas pequeñas y medianas, completar datos faltantes, dar seguimiento comercial y generar mensajes reutilizables.

## Stack propuesto
- Next.js + TypeScript
- PostgreSQL
- Prisma ORM
- Tailwind CSS

## Objetivos MVP
- Importar prospectos desde CSV/Excel
- Clasificar por segmento y tamaño
- Editar datos faltantes (teléfono, email, web, dirección, contacto)
- Estados de seguimiento comercial
- Notas e historial
- Generación de mensajes para WhatsApp/correo
- Plantillas reutilizables
- Filtros y dashboard básico
